🎮 Simulation Controls

🔥 CPU Stress ℹ️

Spawns background PHP processes running hash_pbkdf2(). Server stays responsive — work runs in separate processes, not in the FPM worker pool.

📊 Memory Pressure ℹ️

Allocates large data blocks in shared storage (APCu or file). Multiple allocations stack — mimics gradual memory leak across FPM workers.

🧵 Request Thread Blocking ⚠️

Simulates synchronous blocking operations (sync-over-async antipattern). Causes latency spikes for the duration — observe how blocking code degrades overall system performance.

What to observe:
  • Latency chart shows elevated latency when workers are occupied
  • Probe dots turn yellow/orange as FPM workers become scarce
  • FPM Workers Busy metric increases — at max, new requests queue
